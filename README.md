# Profil organizacji Na Placu

Zawartość repozytorium `na-placu/.github` (publicznego, tylko prezentacja, bez kodu aplikacji). GitHub pokazuje `profile/README.md` na stronie organizacji. Zrzuty w `profile/img/` pochodzą z `na-placu-site/assets/shots/` (zmniejszone, dane demonstracyjne); odnośniki w README wskazują na `raw.githubusercontent.com/na-placu/.github/main/...`, więc obrazki pojawią się po wypchnięciu repozytorium.
